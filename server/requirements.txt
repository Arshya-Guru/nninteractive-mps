# fastapi==0.111.0, numpy, transformers, xxhash, Pillow). On an arm64 Mac, the
# torch 2.8.0 wheel ships with the MPS (Metal) backend, so no special index is
# needed.

# newer release. Hold it on the 2.6.x line, which still has the old signature.
